# 日本語入力とIME

日本語入力は「文字列を編集する処理」と「IMEが変換中の文字・候補を管理する処理」に分かれます。
RTextJP 0.1.0は前者を提供します。

## RTextJPが行うこと

`RTextJPInputUpdate()` はアクティブな入力欄に対して次を処理します。

- raylibの `GetCharPressed()` キューからUnicodeコードポイントを挿入
- 左右、Home、EndでUTF-8文字境界を移動
- Backspace、Deleteで1コードポイントを削除
- Ctrl+VでUTF-8のクリップボード文字列を貼り付け
- 容量不足時に文字境界を壊さず入力を拒否

## RTextJPが行わないこと

- IMEの未確定文字列（preedit）の取得と下線表示
- 変換候補リストの描画
- 候補位置をOSへ通知する処理
- ひらがなから漢字への変換

`GetCharPressed()` がIMEの確定文字を返すかどうかは、利用中のraylibバージョンと
プラットフォームバックエンドに依存します。対象OSで必ず確認してください。

## 外部IME連携から確定文字を渡す

SDL、OS API、独自の画面キーボードなどから確定済みUTF-8を得られる場合は、次のように挿入できます。

```c
void OnImeCommitted(RTextJPInput *input, const char *committedUtf8)
{
    RTextJPInputInsert(input, committedUtf8);
}
```

制御文字と改行は無視されます。不正なUTF-8部分も挿入されません。

## フォント側の注意

入力できても、フォントアトラスにグリフがなければ表示できません。名前入力のように用途を限定する
場合は、ひらがな・カタカナ・使用可能な漢字を文字集合へ含めます。

```c
const char *allowed =
    "名前を入力してください"
    "あいうえおかきくけこ..."
    "アイウエオカキクケコ..."
    "山田太郎佐藤鈴木";
```

任意の文章入力を扱うエディタでは、動的なグリフ読み込みまたは十分な範囲を持つ別のフォント管理が
必要です。RTextJPの固定アトラス補助は、文字集合が予測できるゲームUIを主対象にしています。
