# RTextJP Windows demo

1. Extract every file from the ZIP archive into one directory.
2. Run `rtextjp_01_hello_japanese.exe`.
3. Keep `raylib.dll` and `japanese.ttf` next to the executable.

RTextJP is an unofficial Japanese text helper library for raylib. This project is not part of the
official raylib distribution.

The files in this archive use separate licenses:

- `LICENSE-RTextJP.txt`: RTextJP source and demo program (MIT License)
- `LICENSE-raylib.txt`: raylib runtime (`raylib.dll`)
- `LICENSE-font.txt`: bundled Japanese font
- `README-font.txt`: upstream information for the bundled font

See `README_ja.md` for Japanese instructions.
