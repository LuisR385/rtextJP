# RTextJP Windowsデモ

1. ZIP内のすべてのファイルを同じディレクトリへ展開します。
2. `rtextjp_01_hello_japanese.exe` を起動します。
3. `raylib.dll` と `japanese.ttf` は実行ファイルと同じ場所に置いたままにしてください。

RTextJPはraylib用の非公式な日本語テキスト補助ライブラリです。このプロジェクトは公式raylib
ディストリビューションの一部ではありません。

この配布物には、ファイルごとに別のライセンスが適用されます。

- `LICENSE-RTextJP.txt`: RTextJPのソースとデモプログラム（MIT License）
- `LICENSE-raylib.txt`: raylibランタイム（`raylib.dll`）
- `LICENSE-font.txt`: 同梱した日本語フォント
- `README-font.txt`: 同梱フォントの配布元README

英語の説明は `README.md` を参照してください。
